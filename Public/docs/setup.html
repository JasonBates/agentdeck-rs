Recommended setup

AgentDeck works with Herdr alone, but local-model enrichment is the recommended experience: it turns raw sessions into stable titles, current-step subtitles, and useful outcome summaries.

The compact Recommended setup row is guidance, not an automatic setup wizard. It appears only when a useful configured provider is missing or incomplete. Disabled and unsupported integrations stay quietly hidden, and nothing is installed, pulled, or started for you.

Contextual card headings

AgentDeck uses an explicitly configured local model through Ollama to turn bounded local session context into concise card headings. It does not download or select a model automatically. Configure a model you have chosen and installed; use Herdr-only fallback when the machine cannot carry one.

gemma4:12b is the development reference model. For smaller machines, qwen3.5:4b is the current lightweight documented example; it is not an allow-list or a universal winner. At evaluation time, Qwen's official Qwen3.8 collection had no 4B release, so third-party distillations should be evaluated separately. The public synthetic harness makes that comparison without reading private transcripts.

If heading generation is explicitly disabled, AgentDeck keeps deterministic Herdr-derived headings and does not show an install hint.

[headings]
backend = "auto" # auto, none, or ollama
endpoint = "http://127.0.0.1:11434"
model = "your-installed-model-tag"
title_model = "inherit"    # inherit, off, or another opaque tag
subtitle_model = "inherit"
outcome_model = "inherit"
activity_model = "off"

auto only checks whether the configured Ollama service and model are already available. It never selects, downloads, or pulls a model. Command-line and environment overrides are available through AGENTDECK_MODEL/--model and AGENTDECK_TITLE_MODEL/--title-model.

Claude and Codex capacity

CodexBar capacity and host/local-model telemetry are optional local runtime panels. AgentDeck never manages provider credentials or executes a provider setup command. Capacity first refreshes after one second and then every five minutes; host and local-model readings refresh every five seconds.

[capacity]
backend = "auto" # auto, off, or codexbar

[telemetry]
host = "auto"        # auto, off, basic, or detailed
local_model = "auto" # auto, on, or off

Capacity can retain a last-known reading as stale rather than current; unavailable values stay hidden rather than becoming invented zeroes. Portable host telemetry is basic only, and host = "detailed" reports unsupported. Local-model telemetry observes only the primary configured [headings].model (not per-job overrides) through the local /api/ps endpoint.

Copilot local context

For a validated Herdr Copilot session ID, AgentDeck can best-effort read the local session-state/<id>/events.jsonl file to derive reply age and context usage. It does not read session-store.db, invoke the Copilot CLI, or contact a cloud service. Malformed, unavailable, or unvalidated sessions remain ordinary generic Herdr cards. Copilot transcript-derived generated headings remain disabled.

Supported local transcript enrichment is enabled by default to provide context usage, unread state, reply age, and generated headings where available. Set [transcripts] enabled = false in the TOML configuration to prevent every transcript-file read and retain Herdr/screen-only cards.

AgentDeck follows the local configuration location documented by GitHub for Copilot CLI configuration directories; an absolute COPILOT_HOME may override the home directory.

Tab-title synchronization

Tab-title synchronization is opt-in and off by default:

[tab_titles]
enabled = true

On Unix, it only considers a qualifying single-agent default tab and re-reads Herdr immediately before each rename to verify the same tab, agent identity, and label. Herdr does not offer compare-and-set rename, so a manual rename in the final command race cannot be prevented; it is detected and released on the next pass. Windows title sync is unsupported pending native ACL and reparse-point validation.

Setup commands shown in AgentDeck are display-and-copy only. Review them before running anything in your own terminal.
